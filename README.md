# 断更事件 - 莲灯夜话档案

一个把旧论坛当作游戏场景的中文网页恐怖解谜。玩家不是在菜单里点线索，而是在一份不完整的只读存档里翻版块、帖子、用户资料、站内信和回收站。

## 运行

项目没有构建步骤，也不需要后端：

```bash
cd site
python -m http.server 8000
```

打开 `http://localhost:8000/`。直接双击 HTML 也能浏览，但使用本地 HTTP 服务时图片、音频和路由行为更接近部署环境。

## 这次重做的重点

- 入口页改成档案门厅，先建立 03:33 到 03:44 的时间异常，再进入论坛。
- 论坛保留旧 BBS 的版块、楼层和账户逻辑，皮肤改成暗色 CRT 存档层，桌面和手机都有明确的折叠规则。
- 论坛外壳改成原站中心栏加档案监视侧栏。背景使用低透明度的旧房间照片，阅读深入后才逐渐显出角落、夜路和重影。
- 搜索从单一跳转改成不完整索引。结果会混合公开帖、隐藏帖和用户资料，排序与摘要来自真实帖子正文。
- 阅读旁注只保存观察，不显示数字进度；版块增加未读主题、置顶筛选，帖子支持引用和回复，站内信会留下已读记录。
- 三个旧账号已经成为连续主线：版规打开小刀收件箱，03:44打开提灯人草稿，机柜编号打开青灯回收站。三份私密正文少任意一份都无法进入第37楼。
- 恐怖事件改为短暂的图像重读、时间戳错位和页面状态变化。不会用随机全屏鬼脸打断阅读。
- 新增连接帖和人物支线，把相机时间、南城出租屋、值班电话、在线人数、删帖后台、编辑器缓存、房间平面图、隔墙录音、台灯、青灯备份、留言簿和外婆家书串成一张更完整的关系网。帖子底部会出现少量真实论坛式引用链，方便玩家偶遇支线，不会显示任务清单。
- 氛围等级按调查进度单向保存。进入更深一层后，返回首页、搜索或私信不会把色调冲回初始状态，刷新页面也会从同一档案阶段继续。
- 读取达到不同条件后会出现可追溯的事件：右灯短消息、版务留言和系统同步记录。动态私信只会在真实会员会话中投递，游客不会看到伪未读提示。
- 第35楼之后会涌入37条同楼层的复制回复，火星文、乱码、玩家用户名与最近搜索词按固定顺序反复覆盖，刷新后仍保持一致。
- 缺失楼层支持五种收束，由终局中的三次决定组合触发；每个结局都有独立剧情、最后记录、致谢和档案入口。
- 结局页提供「重新开始调查」入口。重玩会清除本轮阅读、事件、私信和选择，但保留已解锁的结局档案，方便连续体验不同结局。

## 目录

```text
site/
├── index.html                    入口档案门厅
├── bbs/index.html                论坛单页应用
└── assets/
    ├── bbs.js                    原始路由与账户引擎
    ├── bbs-enhance.js             搜索索引、未读状态、笔记和帖子操作
    ├── bbs-data-core.js           核心版块、主帖、第37楼和账号
    ├── bbs-data-story.js          主线帖、站长日志和提灯人草稿
    ├── bbs-data-filler.js         论坛日常帖
    ├── bbs-data-expansion.js      新增连接帖、人物支线和分支选择
    ├── bbs-data-branches2.js      房间、证人、版主、访客与家书支线
    ├── atmosphere-state.js        跨路由保存并恢复档案氛围等级
    ├── archive-events.js          条件触发的短消息、警告和系统事件
    ├── endings.js                 基于阅读行为的五种论坛尾记录
    ├── atmosphere.css              暗色 CRT 视觉、响应式和状态样式
    ├── audio.js                   低音量程序化房间底噪
    ├── scare.js                   渐进式异常事件
    └── img/*-v2.jpg               统一年代感的论坛附件图
```

## 进度状态

浏览记录、提示等级、已读私信和玩家回复都写入浏览器 `localStorage`。想重新体验，可在浏览器开发者工具中清除本站数据，或使用新的无痕窗口。

本作人物、论坛和事件均为虚构改编，与真实人物和平台无关。

作者测试可直接打开 [`docs/walkthrough.html`](docs/walkthrough.html)，其中包含当前三账号最短路线、五结局选项和卡关排查。
