# 断更事件——莲灯夜话档案

一款网页恐怖解谜游戏（半ARG），改编自天涯"左央事件"（已全员化名虚构化）。

「莲灯夜话」是一个2003年成立、2012年关站的灵异论坛。2005年2月，用户「右灯」在怪谈版直播亲身试验通灵游戏，在"四角游戏"直播中途断更，下落不明。最近有人发现，这个早就关闭的论坛，还能打开。

## 玩法

这就是一个（假的）论坛，像逛真论坛一样玩：

- **逛**：版块→帖子→楼层；怪谈版是主线所在
- **搜**：顶部搜索框。带<span>点状下划线</span>的词是系统标记的检索词，点击即搜；关键帖只能搜出来
- **登**：登录不同人的账号（账号密码藏在帖子里），看他们的短消息、回收站
- **记**：右上角「调查笔记」= 故事背景 + 当前进度（关键文档 X/36）+ 下一步目标

## 运行

纯静态站，无依赖、无后端：

```bash
cd site
python -m http.server 8000
# 打开 http://localhost:8000
```

部署直接把 `site/` 丢到 GitHub Pages / 任意静态托管即可。
