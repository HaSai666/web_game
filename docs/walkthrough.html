第37楼的门禁原理

这五个名称只适合作者调试，不应该直接显示在游戏论坛里。玩家只会通过页面变形、异常回复和帖子内容感知自己正在接近真相。

为什么旧攻略里写着“36份文档”
最早版本逐项检查36份核心文档，上一版又只检查五类证据，导致账号可以被公开帖子绕过。当前版本采用“3份私密记录 + 5类证据 + 第35楼第五声”门禁；不必读36份，但三个账号必须实际破解。

通关时应该拼出的核心真相

  1. 右灯把正在看直播的论坛用户算成四角游戏的一部分，网页成为第四盏灯。
  2. 所谓第五声不是第五个人报数，而是那个不该被点名的空位置开始要求身份。
  3. 第37楼不是普通删帖。它是页面里缺失的一个位置，会借当前读者、当前账号或当前名字补全作者字段。
  4. 青灯能封存页面，却无法删除位置；右灯能回来，却必须借一次阅读、返回或回应动作。
  5. 最终三次决定本质上是在回答：谁回应，谁占位，谁保管这份记录。

卡关排查

先按症状定位。大多数问题都来自“只搜到但没点进正文”、旧浏览器进度残留，或者最后少点了一次结局确认。

第36楼仍写“下一楼（不存在）”

  1. 确认已分别打开 pm_youdeng、draft2、del_37 三份私密正文。
  2. 确认已打开一篇房间记录，例如 x_rent_37。
  3. 确认地址是 #/thread/主题ID，不是 #/search/关键词。
  4. 再进入主帖第4页，确认第35楼和第36楼都已渲染。

搜索“第37楼”却进不去

搜索只是入口，不是门票。必须同时满足三份私密记录、五类证据和第35楼第五声；少一项，直接地址也会显示“指定主题不存在”。

没有看到37条乱码回复

必须先让论坛至少进入第三层，再在主帖第4页真正加载第35楼。批次插在第35楼之后，标题应写“显示回复：37　实体记录：0”。

游客状态下出现了私信

当前版本不会给游客生成、记录或展示动态私信；登录后事件才会重新判断并投递。若旧标签页仍有提示，请进入“重新开始调查”清旧存档后刷新验收。

最快路线看不出样式变化

按新路线核对：读小刀私信后应为第1层；读《交代（中）》后第2层；打开机房通知后第3层；主帖第35楼后第4层。回首页、退出账号和刷新均不能倒退。

点完选择却不像结局

三次选择后还要点“读取真正的结局”。闭幕提示出现后，再点“查看结局正文”。完整结局必须包含剧情、记录、致谢和 THE END。

回首页后样式没有恢复

这是当前设计的预期行为。调查状态单调递增，回首页、误触导航或刷新都不会把论坛突然还原。只有“重新开始调查”会清除本轮状态。

旧进度让测试结果混乱

最稳妥的方法是使用无痕窗口。也可以进入“重新开始调查”，清除阅读、私信、支线选择、异常事件和登录状态。

想测试另一个结局

从结局正文或结局档案进入“重新开始调查”，点击确认清除。它会保留已解锁结局档案和静音设置，然后按最短路线重新进入第37楼。

重开后还有已读结局

这是有意保留的收集进度，不是残留错误。重开只清本轮调查，bbs_endings_seen 与声音设置不会被删除。

主帖第35楼后出现37条异常缓存回复。
门禁三份私密记录少任一条时保持“下一楼（不存在）”。
终局三次选择后出现真正的结局读取按钮。
归档结局正文结束后可进入结局档案和重新调查。
推荐的作者验收方式 先用无痕窗口走一遍“最短必通路线”，确认门禁和任意一个结局；再用“重新开始调查”连续测其余四个结局。这样不会被开发期间遗留的浏览器存储干扰。
