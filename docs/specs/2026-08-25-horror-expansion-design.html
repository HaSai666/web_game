01 / Executive summary

执行摘要

当前版本的内容数量并不低，但玩家体验仍显得短且不恐怖。根本原因不是帖子不够多，而是关键内容集中在少数页面、隐藏支线缺乏主线后果、终局存在捷径、视觉阶段差异主要停留在颜色变化，以及恐怖事件没有形成“发生—恢复—延迟回响”的连续过程。

310现有楼层
8帖子内选择
13条件动态事件
5现有结局

本次设计的核心改动

将游戏扩成内部七幕、约80—100分钟的首次通关流程；新增约23个剧情主题与140—180个有效楼层；取消“找到第十一法立即通关”；建立五类证据与五种污染方向；让火星文、编码乱码和HTML结构泄漏成为剧情语言；保留两次与剧情强绑定的短闪帧；深化现有五个结局而不是继续堆叠结局数量。

设计目标

  • 论坛前期足够可信，后期才明显失控。
  • 不同调查路线产生不同污染顺序。
  • 恐怖事件有前兆、爆发和延迟回响。
  • 玩家自己的操作逐渐成为旧论坛内容。
  • 所有必要线索保持可读，不用乱码强迫解谜。

非目标

  • 不做频繁鬼脸、爆音或随机惊吓。
  • 不把整站简单刷成红色作为“后期”。
  • 不伪装系统病毒、安全警告或真实权限请求。
  • 不让玩家必须读完每一篇支线。
  • 不显示章节、等级、证据数量或真相进度。
02 / Decisions

已确认决策与方案比较

方案一：全局阶段式腐化

固定进度统一更换全站样式。

  • 优势：节奏明确、实现稳定。
  • 代价：容易暴露隐藏进度条，重玩顺序固定。

方案二：证据驱动污染网络

调查内容决定论坛被污染的区域与语言。

  • 优势：支线有真实后果，重玩路线不同。
  • 代价：状态组合与验收工作量较大。
  • 吸收方案三的两个高潮闪帧。

方案三：固定恐怖场景

集中制作少数高冲击演出。

  • 优势：冲击力强、易于控制。
  • 代价：场景之间仍然普通，像等待机关。
决策项最终选择设计含义
总体恐怖强度渐进混合 B前期可信、中期局部污染、后期大批乱码与结构失控。
视觉惊吓关键闪帧 B全游戏仅两次，无正脸鬼图，不使用廉价跳脸。
乱码作用可读污染 B约八成氛围噪声，两成残句、用户名、时间与操作线索。
声音接入交互后自适应 B首次点击后接通，随剧情变化，静音入口始终可用。
整体编排证据污染网络五类证据污染五类论坛区域，全球阶段只控制强度上限。
03 / Current narrative

当前主体梳理

当前阶段现有剧情玩家行为现存问题
存档入口关门人于2023年恢复莲灯夜话，声称旧站有36页却有人见过第37页。浏览版块、学习搜索。进入主题很快，正常论坛生活建立不足。
右灯其人右灯表面胆大，实际怕黑、怕独处，需要网友证明“有人在场”。阅读旧帖、资料和朋友回复。人物信息分散，玩家还未产生情感就进入事故。
三次实验削苹果、香灰拌饭、血腥玛丽，从手抖发展到镜中人慢半拍。搜索实验记录、配图、编辑记录。每次实验都像一段摘要，结构和异常含义重复。
四角直播右灯独自进行需要四人的游戏，把论坛观众当成“在场者”。滚动阅读主帖34—36楼。直播被一次性读完，没有实时切换与等待感。
第37楼36楼后跳到38楼，03:44曾出现四字回复并被整体抽走。查公告、回收站和服务器。第十一法可直接解锁终局，形成最短捷径。
失踪余波右灯失踪、2008账号回归、提灯人交代、论坛2012关闭。破解账号、读私信与草稿。2005—2008与2012—2023的情感过程被快速跳过。
玩家感染页面私信玩家、改变输入框和在线人数，玩家成为第五个在场者。做选择并进入结局。大多数选择只在结局文案里结算，中途后果不足。

核心诊断

“主体太短”和“完全不恐怖”是同一个结构问题：玩家没有足够长时间相信论坛、熟悉人物和形成阅读习惯，页面也就没有机会逐步破坏这些习惯。扩写必须先建立稳定秩序，再让异常一层层侵入，而不是直接增加更多“03:44”和“第五声”。

04 / Canon layers

叙事真相分层

为避免“故意留白”变成“叙事矛盾”，后续所有稿件按三层口径写作。

第一层：可核实事实

论坛时间戳、房间物理痕迹、服务器日志、账号登录、警方记录。它们可以损坏，但不得随作者需要任意改变。

第二层：人物证词

小刀、邻居、房东、蛤蟆、青灯、提灯人与关门人的叙述。允许互相矛盾，但每个人必须有自身动机与认知边界。

第三层：被污染记录

第37楼、错位编辑、2008回归帖、模仿标点、引用当前访客。这一层可能主动制造假线索，但污染规律必须一致。

内部真相

空角是仪式的安全阀。右灯把观众当成在场者，第五声出现后多出的身份需要被认领。论坛不是单纯闹鬼，而是在保存并继续执行一次没有结束的“凑数”。

05 / Extended player flow

扩写后的完整玩家流程

幕名仅供内部编剧和状态控制，绝不显示在游戏界面。

第一幕约6—8分钟

旧站看起来一切正常

玩家在普通水帖、怪谈和版务公告中熟悉论坛。右灯主帖只是众多旧帖之一。论坛保持稳定，只发生“已读标记未消失”和时间戳轻微矛盾。首要问题是右灯究竟在炒作，还是确实出事。

正常论坛建立零级异化第一处细微错位
第二幕约10—12分钟

右灯还只是右灯

补足右灯与小刀的线下关系、南城搬家、外婆去世、借台灯和夜间版聊。玩家先学会辨认右灯正常时期的语气、标点、玩笑和胆怯，后续的模仿才有恐怖意义。

人物基线生活关系在场母题
第三幕约18—22分钟

三次实验

每个实验扩成“准备帖—直播记录—旁观者证词—次日后果”。削苹果污染照片，香灰拌饭污染声音和路线，血腥玛丽污染动作与身份。玩家首次遇到局部火星文，但仍可解释为设备故障或网友恶作剧。

图像污染声音污染身份污染
第四幕约16—20分钟

四角直播

直播拆成准备、关灯、第一圈、第五声、失联、报警和锁帖。玩家在主帖、私信、闲聊版和站务版之间切换；返回页面时新增回复。房间、论坛、楼道和服务器四个空间同步失控，出现第一次短闪帧和首批成片乱码回复。

多页面同步第一批乱码第37楼仍封闭
第五幕约10—14分钟

失踪后的三年

小刀寻找右灯，房东、邻居、警方和家属给出冲突证词；青灯恢复第37楼失败；蛤蟆因自责退出；周年打卡出现陌生账号；2008年的右灯账号回归。谜题从“去了哪里”转为“回来的是谁”。

情感后果证词矛盾身份谜团
第六幕约10—14分钟

关站与存档感染

串联2012机房、青灯关站、2023关门人恢复工作和当前访客。旧帖子开始引用玩家搜索词与选择，出现第二次短闪帧。玩家意识到存档不是记录事故，而是在等待新的在场者。

当前玩家入戏第二次闪帧结构污染
第七幕约8—10分钟

第37楼与结局

玩家在五类证据中各获得至少一份后进入第37楼，并连续决定是否回应第五声、是否保留空位置、记录交给谁或删除谁的名字。现有五个结局获得独立终局场景与人物后日谈。

06 / Content package

新增内容清单与体量

A. 右灯人物线：4个主题
  1. 《第一次见右灯真人》：小刀回忆线下见面；右灯进入无窗包间后坚持让门留一条缝。
  2. 《南城租房求助》：宽带、房租与夜间停电问题；37号房首次作为普通地址出现。
  3. 《半夜留灯是不是浪费电》：建立右灯正常时期语言、标点、玩笑与对黑暗的恐惧。
  4. 《蛤蟆和外婆认识吗》：揭示蛤蟆年轻时见过类似的“补缺送众”仪式。
B. 三次实验线：6个主题
  • 削苹果：器材与照片测试；冲洗店发现镜中影像和原图时间不同。
  • 香灰拌饭：午夜路线与末班车；司机和便利店员看见多出的脚步却看不到第二个人。
  • 血腥玛丽：浴室录音与动作不同步照片；青灯发现删除请求来自冻结后的账号。
C. 四角直播线：4个主题
  1. 直播开始前的水楼：正常闲聊中在线人数从4变成5。
  2. 值班电话记录：接线员听见“四个角都有人吗”。
  3. 南城住户实时帖：墙内拖椅声与直播时间同步。
  4. 锁帖临时讨论：版主争论删除、锁帖或报警，主帖自行增加乱码楼层。
D. 失踪余波线：5个主题
  1. 小刀前往南城寻找右灯。
  2. 房东、邻居、警方证词汇总。
  3. 青灯第一次恢复第37楼失败。
  4. 蛤蟆退出论坛前的最后一帖。
  5. 2006周年打卡楼完整版本。
E. 关站与存档感染线：4个主题
  1. 2012年机房连续值班日志。
  2. 三名站务人员决定关站的内部讨论。
  3. 关门人恢复存档的前五次工作记录。
  4. 2023访客邮件与当前玩家记录。

07 / Evidence contamination network

证据驱动的污染网络

全球阶段只规定“最多能恐怖到什么程度”，五类证据决定“具体哪里发生变化”。因此两名玩家即使处于相同进度，也可能先看到完全不同的异常。

人物证据

污染右灯语气、标点、签名和私信。让论坛逐步学会模仿一个人。

房间证据

污染背景、门框、椅子和角落轮廓。让论坛四区与房间四角对应。

仪式证据

污染报数、楼层号和在线人数。让第37楼作为“位置”而不是帖子出现。

身份证据

污染头像、用户名、作者字段与引用对象。让“账号”和“人”逐渐分离。

服务器证据

污染时间戳、分页、导航、缓存和HTML结构。让页面开始暴露内部字段。

关键约束

污染不会因为回首页、打开私信或刷新而降低；但它也不会在玩家尚未接触相关证据时提前暴露。例如，没有读房间线就不会直接出现明显椅子人影，没有读身份线就不会发生头像与签名互换。

08 / Visual progression

论坛逐渐灵异化的六个内部阶段

阶段编号仅用于内部状态，游戏中不显示。

阶段明确进入条件单向状态规则
0级新调查默认状态尚未确认任何实验异常。
1级首次确认实验记录与旁证不一致刷新、返回首页和登录不会降回0级。
2级五类证据中任意两类各获得一份只启用玩家已经接触过的证据污染方向。
3级主线抵达四角直播的第五声无论支线顺序如何，直播都是第一次明确失控锚点。
4级至少获得四类证据，并读过关门人最后日志或恢复过37楼快照允许大批乱码和旧帖引用当前玩家。
5级五类证据各至少一份，并主动进入第37楼保持到本轮结局结束；只有“重新开始调查”可清除。
STAGE 0 / 可信

真实旧论坛

  • 冷灰、暗绿、整齐表格。
  • 背景房间几乎不可辨认。
  • 在线人数固定为4。
  • 没有乱码与突然动画。
STAGE 1 / 泄漏

细小不一致

  • 签名偏移1像素。
  • 时间戳偶尔重复。
  • 已读标记重新出现。
  • 单个非原编码字符。
STAGE 2 / 占位

证据局部污染

  • 背景开始出现门线和椅子。
  • 头像、签名、分页局部错位。
  • 回复框出现未输入残句。
  • 颜色转为褪青绿与烟褐。
STAGE 3 / 模仿

论坛开始学人

  • 明确出租屋轮廓与不对称边栏。
  • 冻结账号显示在线。
  • 正常文字逐字变成火星文。
  • 第一批空作者回复出现。
STAGE 4 / 爆发

大批乱码回复

  • 一次出现12—20层污染回复。
  • 楼层号倒序、重复或全为37。
  • 刷新只改变排列，不会清除。
  • 污染会转移到其他版块。
STAGE 5 / 终局

结构对齐

  • 论坛四区与房间四角对齐。
  • 在线人数固定为5。
  • 乱码先归零，页面异常安静。
  • 选择后乱码拼出完整终句。

“变化必须明显”的硬规则

每次进入更深状态，必须同时改变以下至少三项：色彩、背景内容、文字编码、表格结构、头像与用户名、页面行为、声音、导航与分页。只调暗背景或只换成红色不算一次完整升级。

09 / Corrupted reply grammar

火星文、乱码与结构泄漏系统

乱码不是随机装饰，而是三种具有不同叙事来源的“污染方言”。玩家不必全部解码，但能从两成可读残句中发现人物、时间、关键词和自己的操作。

污染方言表面解释真实用途使用位置
2000年代火星文网友恶作剧、年代用语让实体尝试模仿普通人早中期单层回复、假账号
编码乱码 / Mojibake旧站转码损坏在乱码里保留半句警告或名字缓存、编辑记录、批量回复
HTML结构泄漏页面模板错误证明玩家正被当成字段写入服务器线、后期引用、终局

乱码批次示例

#37　水晶之恋　03:44

#37　青灯　03:44

#37　（作者字段为空）　03:44
4　4　4　4　5
珴卜侍右燈　珴只侍借他啲字

#37　唯物主义小刀　03:44
[quote floor="37" author="当前访客"]
你刚才为什么回头
[/quote]

#　　系统　03:44
<td author="">到你了</td>

#38　半夜鸡叫　03:44
锟斤拷锟斤拷锟斤拷　門外冇亾

生成与使用规则

  • 每个乱码批次使用预写片段组合，不生成完全随机废话。
  • 约80%负责压迫感，约20%承担残句与线索。
  • 每批至少隐藏用户名、时间、关键词、警告、玩家操作或下一支线入口中的一项。
  • 忽略乱码也可通关；仔细阅读只增加证据、角色理解或结局倾向。
  • 同一污染句不会在无剧情原因时跨角色重复。
  • 批量乱码不覆盖导航、静音、返回与重玩入口。

10 / Horror set pieces

关键恐怖演出脚本

场景一：削苹果照片第二次打开

STAGE 1 → 2
触发
玩家第一次看完实验记录，离开后从相关记录再次打开照片。
画面
照片主体不变，镜面中的蜡烛位置向左偏一格；图片说明仍声称“原图没有其他人”。
文字
楼下新增冲洗店回复：“我保存的那张没有镜子。”其中一个“是”写成火星文“昰”。
声音
一次很轻的鼠标双击声，实际玩家只点击了一次。
回响
数分钟后，右侧反射帧也出现同一偏移，但页面不弹窗解释。

场景二：香灰路线多出一步

STAGE 2
触发
玩家依次读过路线帖、司机证词和右灯的脚步记录。
画面
路线附件仍有四个转弯，图例却显示五个节点；第五节点位于右灯出租屋内部。
文字
便利店员回复先正常显示，离开视口再滚回时，末句变成“伱後面那個冇買嘢”。
声音
页面滚动停止后出现一次额外脚步；静音模式显示“页面外记录到一次无方向敲击”。
回响
主页最后发表时间短暂提前一分钟，暗示脚步比右灯先到家。

场景三：血腥玛丽删除附件

STAGE 2 → 3
触发
玩家比较两张动作不同步照片，并打开青灯的附件删除记录。
画面
第一张照片镜中人慢半拍；第二张删除记录里，缩略图只剩镜中人的手，没有现实中的手。
文字
删除人显示右灯，但请求时间晚于账号冻结。引用按钮会引用到一个不存在的作者字段。
声音
轻微玻璃摩擦声；无爆音。
回响
之后所有右灯回复开始多用句号，为身份模仿线埋下可比较基线。

场景四：四角直播第五声

STAGE 3 → 4 / 闪帧一
触发
玩家在主帖看到“一、二、三、四”第三轮结束，并至少打开过一个同步证人页面。
画面
直播照片约150毫秒多出站在房间中心的模糊人形，无正脸；随后恢复，图片说明少一个字。
文字
主帖一次涌入12—20条乱码回复，楼层号重复为37，作者来自不同年代。
声音
第四声报数之后停顿；页面先出现“第五声”文字，音轨半拍后才传来呼吸。
回响
离开主帖后，部分乱码转移到闲聊版；主帖重新看似正常，但在线人数不再回到4。

场景五：2005年的帖子引用当前玩家

STAGE 4 / 闪帧二
触发
玩家完成一项支线选择，并在数分钟后打开对应的旧年份帖子。
画面
约180毫秒显示一张2005年论坛截图，其中包含玩家刚搜过的词或刚做出的选择。
文字
闪帧后页面新增旧年份回复，引用对象是“当前访客”，正文问“你刚才为什么选择那一边”。
声音
一声很轻的回车键；静音模式下回复框光标向下跳一行。
回响
玩家的搜索词进入最近发表摘要，证明当前操作已被旧索引归档。

场景六：第37楼异常安静

STAGE 5
触发
五类证据各至少获得一份，玩家主动进入第37楼。
画面
此前所有乱码短暂消失，论坛变得异常整齐；背景四角与页面四个主要区域对齐，正中间留白。
文字
正文不立即给出结局，而是依次要求玩家决定回应、空位与记录归属。
声音
所有底噪停止数秒，随后出现第五次呼吸。
回响
根据选择，乱码重新出现并逐渐拼出对应结局的最后一句完整话。

12 / Audio

声音递进与静音等价体验

阶段声音内容文字等价表现
前期CRT电流、远处风扇、极轻房间底噪监视条正常轻微跳动
中期方向不稳定的敲击、鼠标双击、椅腿摩擦“页面外记录到三次无方向敲击”
直播报数与页面文字错开半拍报数字段先出现，时间戳后更新
后期磁带呼吸、远处键盘、静音后的一次敲击光标自行向下一行，监视条在静音时跳动
终局全部静默数秒，随后第五次呼吸在线人数从空白恢复为5
  • 声音只在玩家首次点击后接通，符合浏览器自动播放限制。
  • 不使用尖叫、爆音与不可预测的高音量峰值。
  • 静音按钮始终可见；声音偏好在重玩后保留。
  • 任何声音线索都有文字或视觉等价物，静音模式剧情完整。

取消“读完全部36份”与“找到第十一法立即通关”两个极端。新门槛要求五类证据各至少一份，但每类均有多个入口。

证据类示例入口一示例入口二示例入口三

玩家看不到证据数量。足够深入时，论坛通过页面异常暗示：搜索框开始保留查询、缺楼链接从灰色变为可用、在线人数稳定为5、旧帖子引用当前访客。第十一法只提供仪式证据，不再是万能钥匙。

14 / Endings

五个结局的独立高潮

终局包含三次决定：是否回应第五声、是否保留空位置、记录交给谁或删除谁的名字。五个结局不再只是替换文案。

ECHO / 回声

页面没有把你送回去

玩家不回应也不删除。离开第37楼后，每个浏览过的帖子都多出相同回复。主页恢复平静，但搜索框保留四个未输入的字。

OCCUPIED / 占位

有人替你占了那一楼

玩家回应第五声并填入空位置。账号名称从全站消失，自己的文字被归档成第37楼，致谢页作者字段为空。

SEALED / 封存

门关上了，文件名还在里面

玩家以青灯权限封存记录。版块逐个关闭，乱码停止；青灯最后一封私信表示她终于可以离开机房，只有风扇仍在转。

RETURN / 回归

主页多了一位访客

玩家允许右灯通过私信返回主页。旧论坛出现“刚刚发表”的右灯主题；页面关闭前，在线人数从5变成6。

SILENT / 静默

所有异常都被清理干净

玩家删除自己的名字和查询记录。论坛完全恢复正常，恐怖元素消失；致谢结束后，浏览器标题仍显示“还有1人正在输入”。

结局后返回论坛仍保持本轮异化状态；只有主动选择“重新开始调查”才清除污染。已解锁结局档案与声音偏好继续保留。

16 / Fallback & safety

异常降级、可访问性与安全边界

异常情况降级行为不得发生
污染脚本加载失败论坛保持可信旧站状态，正文与搜索仍可用。空白页、无法导航或卡死终局。
本地状态损坏仅重建本轮证据与事件状态，尽量保留已读结局和声音偏好。不断报错、无限弹窗、自动清除全部数据。
图片缺失显示符合旧论坛语境的附件损坏占位与文字说明。关键证据仅存在于图片像素中。
音频自动播放受阻保持静音并显示对应监视条或文字记录。因无声音无法继续。
减少动态效果闪帧改成静态错帧，禁用抖动、呼吸与快速闪烁。仍强制播放高频视觉变化。
移动端空间不足乱码楼层纵向排列，边栏折叠为记录区。横向溢出遮挡导航或选择。
  • 不伪装操作系统错误或真实安全警告。
  • 不请求摄像头、麦克风和通知权限。
  • 不使用突然爆音和正脸鬼图。
  • 不让乱码覆盖关键导航与静音按钮。
  • 所有必要线索都有可读版本。
  • 刷新与返回不会降低异化状态。
  • 静音模式拥有等价视觉提示。
  • 重玩清除本轮污染但保留结局档案。
17 / Acceptance criteria

验收标准

  • 五类证据均可通过至少两条不同路线获得。
  • 任何关键线索都有两个入口，不因漏词卡死。
  • 不读全部支线也能通关，但不能十分钟直达。
  • 十二个事件按条件触发，不会连续轰炸。
  • 每次阶段升级至少改变三种表现维度。
  • 乱码残句与当前剧情、角色和玩家选择一致。
  • 大批乱码后仍能使用导航、返回与静音。
  • 两次闪帧仅在指定剧情点出现。
  • 五个结局拥有不同终局过程和后日谈。
  • 390px移动端不存在横向溢出。
  • 减少动态效果和静音模式完整可玩。
  • 重玩后污染清除、结局档案保留。
  • 控制台无错误，刷新和跨路由状态一致。
  • 任何恐怖模块失效时，基础论坛仍可完成阅读。
18 / Future implementation order

后续讨论通过后的实施顺序

批次工作范围完成定义
第一批：剧本骨架右灯人物线、三次实验、失踪余波；建立角色口吻表和真相分层。新主题可独立通读，时间线无自相矛盾，每篇回答一个旧问题并提出一个新问题。
第二批：证据状态五类证据、软门槛、污染组合和重玩清理。多条路线可通关，第十一法不再直达，返回首页不降低状态。
第三批：视觉与乱码六级异化、三种污染方言、批量乱码、背景与结构变化。阶段差异肉眼明显，关键导航始终可用，乱码残句可核验。
第四批：动态演出十二事件、两次闪帧、自适应声音、延迟回响。事件不随机、不重复、不连续打断；静音与减少动态效果完整。
第五批：终局三次终局选择、五个独立高潮、后日谈与结局档案。每条结局路线拥有独立场景，重玩状态准确。
第六批：完整QA桌面、390px移动端、刷新、深链、五条结局、故障降级、线上部署。全部验收标准通过后再更新GitHub Pages。

本策划稿获复审后仍应先写剧情数据，再做视觉和事件。不能先制作乱码特效再为它寻找剧情触发点，否则恐怖会重新退化成随机网页机关。
