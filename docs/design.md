# 《断更事件——莲灯夜话档案》设计文档

网页搜索式恐怖解谜（半ARG）。改编自天涯"左央事件"（2005年《关于几种恐怖游戏的亲身体验》），全部人物、论坛名均已化名虚构化。

## 一、核心设定

- **舞台**：灵异论坛"莲灯夜话"（2003–2012，已关站）的民间存档站，2023年由老用户"关门人"搭建。
- **玩家身份**：2024年的怪谈考据爱好者，听说这个存档站"有36页，但有人见过第37页"，慕名而来。
- **主要交互**：站内搜索框、旧论坛版块、用户资料、短消息、回收站和少量帖子内选择。阅读页面 → 从自然语句里找到关键词 → 进入隐藏页面 → 让不同视角互相校验。
- **档案索引**：原始设定有 36 份关键记录，第37楼是溢出记录。当前界面把这个矛盾放在楼层、时间和字段里，不用可见进度条提示玩家。
- **低打断恐怖**：不使用随机跳脸或血腥图。环境音只在用户手势后接通，异常来自文本、时间戳、图片反射、回复框和“对不上”的论坛行为。

## 二、故事时间线（真相全貌，玩家倒序挖出）

- 2004.11　ID「右灯」注册莲灯夜话，活跃于怪谈版。
- 2005.2.20　右灯开帖《关于几种所谓通灵游戏的亲身体验》，宣称亲身试验招鬼游戏并直播。
- 2005.2.20–2.26　实验一（对镜削苹果）、实验二（十字路口吃香灰拌饭）、实验三（血腥玛丽）陆续更新，楼主语气从戏谑逐渐反常。
- 2005.2.27 凌晨　四角游戏"单人直播"。03:33 第36楼更新"到我了"。03:44 第37楼出现又消失，右灯断更。
- 2005.2.27 03:44　ID「提灯人」注册（注册时刻=断更时刻，本作最大伏笔之一）。
- 2008.5　右灯ID回帖一句"我回来了。对不起。"——时间戳显示为 2005.2.27 03:44。
- 2012.9　论坛关站，公告理由是"2月27日机房事故"。
- 2014.3　提灯人在外站发交代帖（存档站收录转载），讲述右灯失踪三年的遭遇与去向。
- 2023.6　站长"关门人"建成存档站，开始考据。
- 2023.11　站长日志停更，最后一条写于03:44："我去找第37楼了。"
- 2024　玩家进入。

**真相（不向玩家明说，全靠拼）**：四角游戏需4人按顺时针走角、拍肩报数，第4人走到的角落应该是空的——空角意味着"游戏成立"。右灯那晚独自在房间里"借"了三个不存在的玩家。报数记录里出现了第5个声音。被数进来的"东西"代替右灯活了下来；2008年回帖的、2014年写交代的，都不是原来的右灯。关门人考据越深越接近"被数进去"，玩家是下一个。

## 三、恐怖递进手段

1. **三层视觉**：
   - T1：冷灰监视器和旧论坛表格，异常只藏在时间与字段里。
   - T2：冷绿/烟褐的陈旧层，照片反射、边框偏移和未登记输入逐渐出现。
   - T3：近黑红褐的终局层，扫描线、重影、反射帧和缺失字段互相叠加。
   颜色状态单向保存，返回首页不会冲回 T1。
2. **访客计数器**：导航栏默认显示 4 人。读到深层记录后变成 5，部分支线会短暂写入 6，再回到 5，不解释来源。
3. **时间戳母题**：03:33 / 03:44 反复出现，玩家自己会学会怕这两个数字。
4. **404腐化**：搜索无结果页读取 localStorage 已访页数，访问越深，无结果页的文字越异常。
5. **隐藏白字**：个别页面用白底白字藏内容，全选才能看见（如P18的"到我了"下面藏着"别数"）。
6. **报数崩坏**：直播楼层文字从正常→重复→乱码（"他回头了他回头了他回头了"）。
7. **标签页标题**：深层页面的 `<title>` 不再是页面名（P37标题为"它在数你"）。

## 四、技术方案

- 纯静态站（`site/` 目录），HTML+CSS+原生JS，无依赖，GitHub Pages可部署。
- `assets/bbs.js`：论坛路由、楼层、账号、短消息、回收站和第37楼门禁。
- `assets/bbs-enhance.js`：不完整搜索索引、未读状态、阅读旁注、引用/回复操作和帖子底部引用链。
- `assets/atmosphere-state.js`：把档案氛围等级写入 localStorage，并保证跨路由单向递进。
- `assets/archive-events.js` 与 `assets/haunt.js`：按阅读条件触发私信、版务警告、系统弹窗、幽灵回复、反射帧和帖子内选择。
- `assets/audio.js`：用户手势后启动的低音量房间底噪，随档案状态改变；静音设置独立保存。
- 密码门：P25–P27（提灯人交代帖）需密码，密码 `0344`（右灯最后在线时刻，线索在P14）。前端简单校验，不做重度混淆（品类惯例）。
- 搜索规则提示（写在首页）：每次1个关键词、仅汉字、不支持空格。

## 七、开发规范

- 每页：`<body class="t1|t2|t3">`，页首面包屑"莲灯夜话存档 >> 板块名"，导航栏显示当前在线数，页脚保留离线镜像时标。
- 页面为"存档截图感"：帖子楼层结构（楼层号、ID、时间戳、正文），不做现代UI。
- 宋体/小字号/表格边框，T1配色参考2005年Discuz!蓝白。
- 关键词在正文中自然出现，不做高亮标注（玩家自己找词）。
- 全站无外链、无真实个人信息；"天涯""左央"等真实名称一律不出现。

## 八、当前剧本扩充

论坛现在由核心主帖、剧情帖、日常水帖和连接支线组成，共 60 个主题、269 个楼层。支线不计入第37楼的必读门禁，避免玩家被数字进度牵着走；它们通过主帖热词、帖子底部的少量引用链和用户签名自然出现。

支线按三条视角组织：

- **右灯的人物线**：`f_rightlamp_note` 说明他为什么需要“有人在场”，把主角从单纯的作死玩家还原成一个害怕无人见证的人。
- **房间与线路线**：`f_door_watch`、`f_room_rental`、`f_phone_line` 把门牌、值班电话和南城房间串在一起。电话线末尾提供回拨/删除记录选择。
- **设备与替代线**：`f_audio_log`、`f_rack_log`、`f_reply_shadow`、`f_editor_cache`、`f_chair_back` 分别从磁带、机柜、标点、缓存和底片留下不一致的证据。编辑器缓存提供展开/关闭选择。

主帖 33 至 39 楼补入编辑器、录音、电话和在线人数的交叉回声，但不显示“当前层级”或“离真相还有多少”。玩家只会看到论坛字段逐渐失去原本的可靠性。

## 九、状态与结局

`bbs_atmosphere_tier` 是单向持久化的档案状态。路由返回首页、搜索、登录或查看私信时，只能保持或加深色调，不能恢复初始皮肤。支线选择、动态事件和玩家回复分别写入独立字段，最终由五个结局收束：回声、占位、封存、回归、静默。

第37楼触发后会先显示独立的结局幕帘，再进入完整结局章节。章节包含发生经过、真相说明、玩家带来的支线证据、最后记录、致谢和重玩入口。结局档案保留已读结局；“重新开始调查”只清除本轮阅读状态，不删除结局索引。
