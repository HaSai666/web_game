# 《断更事件——莲灯夜话档案》设计文档

网页搜索式恐怖解谜（半ARG）。改编自天涯"左央事件"（2005年《关于几种恐怖游戏的亲身体验》），全部人物、论坛名均已化名虚构化。

## 一、核心设定

- **舞台**：灵异论坛"莲灯夜话"（2003–2012，已关站）的民间存档站，2023年由老用户"关门人"搭建。
- **玩家身份**：2024年的怪谈考据爱好者，听说这个存档站"有36页，但有人见过第37页"，慕名而来。
- **唯一交互**：站内搜索框。阅读页面 → 找可疑关键词 → 搜索 → 进入隐藏页面 → 重复。
- **页脚系统**：每页页脚标 `N/36`。集齐36页后出现第37页，页脚为 `37/36`（溢出本身即恐怖点）。
- **无跳脸、无音效、无血腥**。恐怖全部来自文本、时间戳与"对不上"。

## 二、故事时间线（真相全貌，玩家倒序挖出）

- 2004.11　ID「右灯」注册莲灯夜话，活跃于怪谈版。
- 2005.2.20　右灯开帖《关于几种所谓通灵游戏的亲身体验》，宣称亲身试验招鬼游戏并直播。
- 2005.2.20–2.26　实验一（对镜削苹果）、实验二（十字路口吃香灰拌饭）、实验三（血腥玛丽）陆续更新，楼主语气从戏谑逐渐反常。
- 2005.2.27 凌晨　四角游戏"单人直播"。03:33 第36楼更新"到我了"。03:44 第37楼出现又消失，右灯断更。
- 2005.2.27 03:44　ID「提灯人」注册（注册时刻=断更时刻，本作最大伏笔之一）。
- 2008.5　右灯ID回帖一句"我回来了。对不起。"——时间戳显示为 2005.2.27 03:44。
- 2012.9　论坛关站，公告理由是"2月27日机房事故"。
- 2014.3　提灯人在外站发交代帖（存档站收录转载），讲述右灯失踪三年的遭遇与去向。
- 2023.6　站长"关门人"建成存档站，开始考据。
- 2023.11　站长日志停更，最后一条写于03:44："我去找第37楼了。"
- 2024　玩家进入。

**真相（不向玩家明说，全靠拼）**：四角游戏需4人按顺时针走角、拍肩报数，第4人走到的角落应该是空的——空角意味着"游戏成立"。右灯那晚独自在房间里"借"了三个不存在的玩家。报数记录里出现了第5个声音。被数进来的"东西"代替右灯活了下来；2008年回帖的、2014年写交代的，都不是原来的右灯。关门人考据越深越接近"被数进去"，玩家是下一个。

## 三、恐怖递进手段

1. **三层视觉**：
   - T1（P01–P14）：正常2005年论坛，蓝白表格、宋体小字。
   - T2（P15–P24）：暗黄陈旧，页脚偶尔错位，个别字泛红。
   - T3（P25–P37）：深红近黑底，文字抖动（CSS微动画）、乱码渗入、行距崩坏。
2. **访客计数器**：全站页脚固定显示"当前在线：4人"。P36起变为"5人"。不解释。
3. **时间戳母题**：03:33 / 03:44 反复出现，玩家自己会学会怕这两个数字。
4. **404腐化**：搜索无结果页读取 localStorage 已访页数，访问越深，无结果页的文字越异常。
5. **隐藏白字**：个别页面用白底白字藏内容，全选才能看见（如P18的"到我了"下面藏着"别数"）。
6. **报数崩坏**：直播楼层文字从正常→重复→乱码（"他回头了他回头了他回头了"）。
7. **标签页标题**：深层页面的 `<title>` 不再是页面名（P37标题为"它在数你"）。

## 四、技术方案

- 纯静态站（`site/` 目录），HTML+CSS+原生JS，无依赖，GitHub Pages可部署。
- `assets/style.css`：三套主题（`.t1` `.t2` `.t3`），`<body class="t2">` 切换。
- `assets/forum.js`：
  - `ROUTES` 关键词→页面字典（含同义词多对一）；无匹配跳转 `search.html?q=xxx`（404腐化页）。
  - localStorage 记录 `visited` 页面数组：驱动404腐化程度、P18"下一楼"按钮解锁、计数器4→5。
  - 页码、计数器、隐藏白字、时间戳均为页面静态内容，JS只负责路由与进度。
- 密码门：P25–P27（提灯人交代帖）需密码，密码 `0344`（右灯最后在线时刻，线索在P14）。前端简单校验，不做重度混淆（品类惯例）。
- 搜索规则提示（写在首页）：每次1个关键词、仅汉字、不支持空格。

## 七、开发规范

- 每页：`<body class="t1|t2|t3">`，页首面包屑"莲灯夜话存档 >> 板块名"，页脚 `页码 N/36 · 当前在线：4人`。
- 页面为"存档截图感"：帖子楼层结构（楼层号、ID、时间戳、正文），不做现代UI。
- 宋体/小字号/表格边框，T1配色参考2005年Discuz!蓝白。
- 关键词在正文中自然出现，不做高亮标注（玩家自己找词）。
- 全站无外链、无真实个人信息；"天涯""左央"等真实名称一律不出现。
